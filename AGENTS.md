# pult — инструкции агенту

## Автономная работа по плану

1. Активный план — самый свежий файл в `docs/superpowers/plans/`, где остались невыполненные пункты `- [ ]`.
2. Работай по нему сверху вниз, не спрашивая «продолжать?» и не заканчивая ход между задачами ради отчёта.
3. После каждой задачи: прогнать её проверки (`pnpm typecheck`, `pnpm test`, нужные `cargo test`/`clippy`), закоммитить, отметить шаги в плане.
4. В конце хода — одна строка статуса: `Сделано X/N, дальше Task Y`, и если план не закончен, следующая задача начинается в этом же ходе.
5. Останавливайся только когда: пользователь сказал stop; нужен секрет, логин или подтверждение оплаты; проверка падает по внешней причине и починка уже не помогает; план закончен.
6. Перед остановкой обнови план и запиши точный следующий шаг, чтобы новая сессия продолжила без вопросов.
7. Новые находки по ходу работы дописывай в план (или `TODO.md`) отдельным пунктом, а не держи в голове.
8. Независимые задачи можно отдавать subagent'ам; планирование и ревью — Gemini по правилам глобального `AGENTS.md`.

## Как описывать работу

- Каждый шаг — одна короткая строка: что делаю и зачем. После шага — одна строка результата (тесты/ошибка/вывод), без пересказа кода.
- Не заваливай длинными логами: команды, пути, итог. Детали — только когда что-то сломалось.
