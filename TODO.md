## ⚙️ Функциональные пробелы

- [ ] **Вход в аккаунты из приложения.** ACP `authenticate` типизирован в `protocol/types.rs`, но UI его не вызывает: при «Needs sign-in» пользователь должен сам запустить `codex` / `claude` в своём терминале. Надо: кнопка Sign in → `authenticate` с выбранным authMethod → повторная проверка.
- [ ] **Выбор модели на провайдера.** Wire-тип `configOptions` парсится (акп.rs прокидывает `config_option_update`), но UI не строит чипы/пикер моделей. Нужно перечисление конфиг-опций и `set_model` когда агент заявляет.
- [ ] **Reasoning effort.** Чип «reasoning» сейчас показывает session modes агента (у мока — Code/Architect), а не отдельные уровни рассуждений.
- [ ] **Antigravity** — пользователь им пользуется (входил в аккаунт), но его нет в `detect_installed()` (сейчас: claude, gemini, codex, opencode, dsh). Добавить кандидата с подходящей ACP-инвокацией.
- [ ] **`/usage`** — страница usage из брифа («later») так и не построена — роута нет вообще.
- [ ] **Claude Code и Gemini CLI** — адаптеры проверены только хендшейк-пробами; реальные прогоны с подписочными аккаунтами на этой машине не выполнялись (CLI не установлены).
