# M12 — Usage Insights (`/usage`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A read-only `/usage` screen over persisted ACP `usage_update` events, with honest gauges (context fill at run end, latest reported cost) and no false totals.

**Architecture:** `Store::usage_report` reads existing `events`/`runs`/`threads` rows (latest valid `usage` snapshot per run by max seq), groups by thread/instance without summing gauges; IPC `usage_report` runs it in `spawn_blocking`; pure TS helpers compute KPIs/formatting; the `/usage` route renders KPIs, Runs/Threads/Providers tabs, provider filter, empty/error states.

**Tech Stack:** Tauri 2, Rust/serde/rusqlite, React 19, TS strict, zustand (no store needed here), Tailwind v4, Vitest, cargo test/clippy.

**Spec:** TODO.md (/usage), DEVLOG.md, protocol/acp-schema.json (`UsageUpdate`, `Cost`), store migrations (events/runs/threads), src/stores/runs.ts (usageLine).

**Status 2026-11-14:** Tasks 1–5 done (`f3792f6`), review fix pass committed. Gates: cargo 115/115, vitest 116/116, clippy/typecheck/lint clean. No GUI/Playwright pass.

## Global Constraints

- No SQLite migrations; read-only queries over existing tables.
- Honest semantics: `used`/`size` are context-window gauges; `cost` is agent-reported (per-turn or cumulative). Never render sum(used) or sum(cost).
- TS strict; PultError; outside Tauri `usageReport()` returns an empty report.
- No new dependencies; no GUI/Playwright runs.

## Review Focus

1. No grand totals anywhere (backend or UI).
2. Corrupt/legacy `usage` payloads never break the query or invent rows.
3. Latest valid snapshot per run (max seq), not ts/insert order.
4. No blocking UI thread (spawn_blocking), no lock across await.
5. `/usage` is wired into router/breadcrumbs/palette/sidebar.
